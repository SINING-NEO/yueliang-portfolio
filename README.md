# Yue Liang: Portfolio

Personal portfolio website of Yue Liang (Thawdar Lin Wai), Year 2 Applied AI & Analytics student at Singapore Polytechnic.

**Live site:** https://sining-neo.github.io/yueliang-portfolio/

The earlier version lives at https://yueliangg.github.io/yueliang-portfolio/. This copy adds the JEN Singapore Tanglin work, competitive swimming, Java, a phone menu, and link-preview tags.

## What's inside

- Twelve projects across data analytics, machine learning and web development, each with its own project page
- About, education, competitions and skills
- Résumés for Data Analyst and AI Engineer internships (`resume/`)

## Built with

Plain HTML, CSS and JavaScript, with no frameworks or build step. The hero background is a small WebGL shader, and fonts are Instrument Serif, Outfit and JetBrains Mono from Google Fonts.
